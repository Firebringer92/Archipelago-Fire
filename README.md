# Archipelago-Fire

[Archipelago](https://archipelago.gg) multiworld randomizers for the *Star Wars: Knights of the Old Republic 1 & 2*

## Games

Knights of the Old Republic | 0.2.1 | [KOTOR README](https://github.com/Firebringer92/Archipelago-Fire/tree/main/KotoR#readme) | [KotoR_TEMPLATE.yaml](https://github.com/Firebringer92/Archipelago-Fire/blob/main/KotoR/Docs/KotoR_TEMPLATE.yaml) 
Knights of the Old Republic II: The Sith Lords | Alpha 0.1.0 | [KOTOR 2 README](https://github.com/Firebringer92/Archipelago-Fire/tree/main/KotoR2#readme) | [KotOR2_TEMPLATE.yaml](https://github.com/Firebringer92/Archipelago-Fire/blob/main/KotoR2/Docs/KotOR2_TEMPLATE.yaml) |

Each game is separate, with its own downloads, installer and client. Follow the setup guide for the game you want to play.

## Downloads

Get releases from the [Releases page](https://github.com/Firebringer92/Archipelago-Fire/releases). Each release has two zips; take both from the same release.


## Basic requirements

- Windows
- Your own Steam copy of the game
- Python 3.12 or 3.13 (3.11.9 or newer 3.11 also works; 3.14 does not)
- Archipelago Launcher 0.6.7 or newer, only if you generate or host seeds

## Before you play

These mods change game files. Back up your saves and read the setup guide first. No game files are distributed here: anything built from the game is made on your own PC from your own install.

## Reporting problems

Open an [issue](https://github.com/Firebringer92/Archipelago-Fire/issues). Say which game and version you are using, what you were doing, and attach the logs named in that game's setup guide.
